# Mebi Accessories — website preview

A responsive e-commerce website preview customised around the WhatsApp catalogue screenshots supplied by the business owner.

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Start `index.html` with Live Server (recommended).
4. Test the shop filters, product pages, cart and WhatsApp checkout.
